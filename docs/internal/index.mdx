# Internal — agent-facing and planning docs

These pages serve the **maintainers and AI agents** working on the csl-guides repo, not
site readers. They are deliberately kept out of every public sidebar; each one is
`unlisted`, so it renders only for someone who follows a direct link.

| Document | What it is |
|----------|------------|
| Guides Hypotheses | The site's falsifiable QA agenda (GH-1…GH-5): claim, data, metric, baseline, testing artifact |
| Pref × body residual methods | Typed `pref_only` methods appendix (UC-13) for paper authors and FINDINGS |
| Pref legend naming authority | Metadoc: standing policy that body `.txt` wins for pref legend *naming* |
| Preface front-matter enrichment use cases | Metadoc: UC registry status with milestone verdicts |
| Preface enrichment plan (P0, 2026-07) | Plan record with its roadmap, architecture, implementation and verification companions |

Agents: read Guides Hypotheses before proposing content
changes — an open hypothesis may already cover the idea, and a settled one names the
committed artifact that tests it.
