# Jinadeva, *Abhidhānacintāmaṇi-śiloñcha* (`ACSJ`)

`ACSJ` is the *śiloñcha* ("gleanings") of Jinadeva to Hemacandra's
*Abhidhānacintāmaṇi* (ABCH) — a brief set of further synonyms gathered in the same
kośa form. A small companion to the main kośa.

## When to use it

Use `ACSJ` as a **small companion** to ABCH (and its supplement ACPH) — gleaned
extra synonyms. For meanings in English use [Monier-Williams (MW)](/dictionaries/mw).

## Reading an entry

Brief synonym entries keyed to the kośa's sections. The opening entries
(`csl-orig/v02/acsj/acsj.txt`):

```
<L>1<pc>1
<info kvvv="<s>devADidevakARqaH</s>"/>
<eid>1<syns><s>sarvIya-puM</s>
<eid>4<syns><s>samBava-puM</s>
```

| In the source | Meaning |
|---|---|
| `<info kvvv="…devADidevakARqaH">` | the subject section |
| `<eid>1`, `<eid>4` | entry ids (keyed to the main kośa) |
| `<syns><s>sarvIya-puM</s>` | a gleaned synonym (masculine) |

See [Data Formats](/developers/data-formats) for the markup reference.

## What makes it distinctive

- **"Gleanings" by another hand.** The *śiloñcha* ("gleanings") are Jinadeva's
  additions, gathered from other sources into the same verse form — not
  Hemacandra's own supplement (cf. ACPH), so their synonym choices bear a
  different editorship.
- **Smallest of the Abhidhāna group.** Five pages: the last and smallest layer of
  the kośa family (ABCH + ACPH + ACSJ).
- **Keyed to the main kośa.** Its `<eid>` ids reference main-kośa entries
  (`<eid>1`, `<eid>4`), not a fresh alphabetical sequence.

## Headword key conventions

ACSJ ("gleanings") follows the same synonym-group structure as ABCH — no alphabetical headword key; search matches synonyms in `<syns>`. This is a very short text (~5 pages) with `<eid>` ids referencing the main kośa.

| Convention | Marker / form | Example | Note |
|---|---|---|---|
| Subject section | `<info kvvv="…">` | `<info kvvv="…devADidevakARqaH">` | The thematic section |
| Entry id | `<eid>N` | `<eid>1` | References the main kośa entry |
| Synonym | `<syns><s>word-gender</s>` | `<s>sarvIya-puM</s>` | Gender: `-puM` masc. |
| Search | Search on a **synonym** to find its group | — | No alphabetical headword key |
